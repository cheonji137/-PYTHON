6장: 리스트(List) 심화 및 응용 요약

리스트 조작 및 함수: 요소 추가(append()), 특정 요소 삭제(remove()), 정렬(sort()), 인덱스 찾기(index()), 최댓값/최솟값 계산(max(), min()) 등 다양한 내장 메서드로 리스트 데이터를 관리합니다. 특히 append()와 pop()을 조합해 후입선출(LIFO) 구조의 스택(Stack)을 구현할 수 있습니다.

슬라이싱 및 데이터 수정: numbers[::-2]와 같이 슬라이싱 조건으로 원하는 간격의 요소를 가져오거나, numbers[1:] = [] 처럼 리스트의 특정 범위를 한 번에 비울 수 있습니다. 함수에 리스트를 전달하면 원본 리스트의 요소가 직접 수정(Call by reference 효과)되기도 합니다.

리스트 컴프리헨션(List Comprehension): 반복문과 조건문을 대괄호 내부에 한 줄로 압축하여 새로운 리스트를 생성하는 효율적인 기법을 다룹니다. 이를 통해 누적 합계 리스트 생성, 특정 조건(예: 2와 3의 공배수) 필터링, 2차원 리스트(틱택토 보드) 초기화 등을 수행합니다.

다중 루프와 데이터 탐색: 3중 for문을 이용해 피타고라스 수 조화 (x, y, z) 쌍을 찾아 리스트에 저장하는 등 복잡한 조건의 데이터를 탐색하고 수집합니다.
