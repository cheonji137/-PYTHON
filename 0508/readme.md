7장: 문자열, 세트(Set), 딕셔너리(Dictionary) 요약

세트 (Set): 중복을 허용하지 않는 자료구조입니다. 두 문자열의 교집합(&)으로 공통 글자를 찾거나, 텍스트를 단어 단위로 쪼갠 후 중복을 제거하여 사용된 단어의 개수를 세는 데 활용합니다.

딕셔너리 (Dictionary): 키-값(key-value) 쌍으로 데이터를 관리합니다. 영한사전 구현, 연락처 추가·삭제·출력 시스템 구축, 학생별 성적 리스트의 평균 계산, 문자열 내 단어의 빈도수(등장 횟수) 측정에 사용됩니다.

문자열 조작 및 메서드: 문자열 슬라이싱([::-1])을 이용한 회문(Palindrome) 검사, split()과 대문자 변환(upper())을 활용한 머리글자(Acronym) 추출, 특정 구분자(@)를 기준으로 이메일 아이디와 도메인을 분리하는 기능 등을 다룹니다.

💡 한 줄 요약
중복을 제거하는 세트(Set), 키-값 쌍의 딕셔너리(Dictionary), 그리고 다양한 문자열 내장 메서드를 활용하여 텍스트 데이터를 가공하고 처리하는 방법을 배웁니다.
