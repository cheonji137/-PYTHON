3장: 조건문과 반복문 요약

조건문 (if-elif-else): 조건에 따라 코드를 선택 실행합니다. 논리 연산자(and, or)로 복잡한 조건을 체크하거나, match-case문으로 특정 값에 매칭할 수 있습니다.

반복문 (for, range): 리스트의 요소를 순회하거나, range(시작, 끝)로 지정한 횟수만큼 반복하며 합계나 팩토리얼 등을 계산합니다.

리스트(List): 대괄호([]) 안에 데이터를 나열하여 저장하며, 인덱스(예: [0], [-1])를 사용해 값을 변경할 수 있습니다.

💡 한 줄 요약
if와 match를 사용한 조건별 흐름 제어, for와 range를 활용한 반복 연산, 그리고 리스트의 기본 개념을 다룹니다.
