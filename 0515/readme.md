8장: 클래스(Class)와 객체 지향 프로그래밍 기초 요약

클래스와 인스턴스: class 키워드로 데이터와 기능을 묶은 틀을 정의하고, 이를 통해 독립된 객체(인스턴스)들을 생성하여 각각의 상태를 관리합니다.

생성자 (__init__): 객체가 생성될 때 변수를 초기화하며, 인자값이 없을 때를 대비한 기본값(Default parameter)을 설정할 수 있습니다.

정보 은닉 (캡슐화): 변수명 앞에 언더바 두 개(__)를 붙여 외외부에서 필드에 직접 접근하는 것을 차단하고, Getter와 Setter 메서드를 통해서만 안전하게 값을 읽고 수정하도록 제한합니다.

클래스 변수 vs 인스턴스 변수: 객체마다 각자 가지는 인스턴스 변수와 달리, kind = "Bulldog"처럼 클래스 내부에 선언하여 모든 객체가 공유하는 클래스 변수의 개념을 다룹니다.

특수 메서드 (오버라이딩): 객체를 문자열로 예쁘게 표현하는 __str__이나, == 연산자로 객체 간의 면적 등을 비교 정의하는 __eq__ 같은 내장 특수 메서드를 재정의해 사용합니다.

💡 한 줄 요약
객체 지향 프로그래밍의 핵심인 클래스 구조를 이해하고 생성자, 정보 은닉(__), Getter/Setter, 클래스 변수, 특수 메서드를 활용해 독립적인 객체를 설계하는 방법.
