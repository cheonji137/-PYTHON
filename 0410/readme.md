5장: 함수(Function)와 재귀 요약

함수 정의와 호출 (def): 반복되는 코드를 def 함수명(): 구조로 묶어 필요할 때마다 재사용하고, 함수 내에서 또 다른 함수를 호출하는 방식으로 프로그램을 구조화합니다.

매개변수(Parameter)와 반환값(return): 외부로부터 값을 전달받는 매개변수를 활용하며, 처리된 결과는 return을 통해 전달합니다. 매개변수에 기본값을 지정하거나(count=1), 콤마(,)를 이용해 여러 개의 값을 동시에 반환할 수도 있습니다.

재귀 함수(Recursion): 함수 내부에서 자기 자신을 다시 호출하는 기법으로, 팩토리얼 계산과 같이 반복적인 수학적 구조를 간결하게 표현합니다.

💡 한 줄 요약
코드의 재사용성과 가독성을 높이기 위해 매개변수와 반환값을 갖는 함수를 정의하고 활용하는 방법 및 재귀 함수의 기초를 다룹니다.
